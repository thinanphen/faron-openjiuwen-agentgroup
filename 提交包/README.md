## 叙事主线（一页纸）

> **openJiuwen 的 AgentGroup 解决「一起干活」；法元补上「干得可信」。**
>
> 在涉外法律交付这类高风险场景里，多个 Agent 协同产出的每一处法条引用，
> 都由一段**不经过模型**的确定性规则逐条判定真伪与适用性——
> **评委可以不带任何 API Key，在本地亲手复现这个判定。**

## 评委最短验证路径（约 1 分钟）

```bash
pip install -r ../requirements.txt          # 若只想看自检，可跳过这步

# ① 零依赖验证：不需要框架、不需要 Key，看「第9999条」被当场点名
python ../tests/verify_zero_dep.py

# ② 完整测试向量
python ../tests/test_citation_audit.py      # 31 组
python ../tests/test_assembly.py            # 9 组（装配防线）

# ③ 端到端：图谱 → 检索 → 起草 → 两段自检 → 导出 .docx
python ../run_offline_demo.py
#    产物：../runtime/deliverable_*.docx（含 2 张 Word 原生表格）
```

**不看代码的验证路径**：双击 [`../资料/04-产品演示站/demo.html`](../资料/04-产品演示站/demo.html)
（单文件零依赖，离线可开），进入「**引用自检交互实验室**」，
**自己注入一个库里不存在的条文号，看它当场被点名**。
