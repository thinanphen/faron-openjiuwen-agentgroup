# 03 · 应用场景说明

## 一、目标用户与场景

### 主场景：涉外 / 跨境法律业务

| 场景 | 具体形态 | 法元的落点 |
|---|---|---|
| **中日合资** | 设立合资公司、出资义务、公司治理、股权转让 | 依日本《会社法》《民法》起草审查意见书 |
| **赴美投资** | 商标注册与侵权、合规审查 | 依美国法典 Title 15 出具意见 |
| **跨境贸易** | 货物买卖、交付验收、货款结算、信用证 | 依日本《民法》《商法》梳理请求权基础 |
| **跨境破产** | 债权申报、自动停止效力 | 依美国法典 Title 11 |
| **出口合规** | 外汇与外贸管制 | 依日本《外汇及对外贸易法》 |

### 目标用户

| 用户类型 | 规模特征 | 核心诉求 |
|---|---|---|
| **涉外律师** | 中小所 / 精品所为主 | 高频查日美法条；文书要能直接交付客户 |
| **企业法务** | 有跨境业务的制造/贸易企业 | 涉密合同**不能上传云端**；要内部可审计 |
| **合规岗位** | 出口管制、反商业贿赂 | 需要可溯源的合规依据 |

---

## 二、为什么这个场景值得做

### ① 高频刚需

「审合同 → 出文书」是律师每天的重复劳动。法元把它变成：粘贴合同 → 出意见书草稿 → 人工复核。

### ② 涉外场景的**信息差**是真实痛点

中国律师查日本《民法》、美国法典的原文，通常要跨语言、跨网站、跨检索习惯。
法元把 **152,940 条**日美官方法条装进本机，**装机即用、不联网导入**。

### ③ 合规诉求直接决定采购

> 律所/企业法务对「涉密文书是否出内网」有一票否决权。

法元**单机运行、数据不出本机、API Key 密文落盘**——这不是加分项，是准入项。

### ④ 高风险域恰好是通用 Agent 最容易翻车的地方

法律结论必须可溯源。「看起来像法条」的生成内容在这类场景里**没有价值甚至有害**。
法元的确定性引用自检回答了「Agent 如何在高风险域建立可信」这个**通用问题**——
这也是它超出「办公」方向示例、具备更广迁移价值的地方。

## 四、典型使用流程（一条线走完）

```
① 打开法元（装机即用，法库已随包分发）
        ↓
② 法规查询：按国家浏览 / 关键词检索
   · 支持中日文条号跳转（「103」/「百三」/「1.2」）
   · 中文输入可命中译名与译文
        ↓
③ 文书智能体「小元」：选择任务类型（5 类之一）
   · 粘贴合同或导入 DOCX / PDF / 图片（本机提取）
        ↓
④ 制定计划卡
   · 先命中案由 → 从知识图谱取构成要件与请求权基础 → 再排步骤
   · 关键步骤可设人工确认闸门
        ↓
⑤ 开始执行
   · 模型自主决定调用哪个工具、给什么参数
   · 只引用工具真实返回的法条（右侧清单带篇名/条号/来源）
        ↓
⑥ 两段自检
   · 第一段：引用是否真实存在（能否在工具真实返回中命中）
   · 第二段：是否落在案由图谱的请求权基础范围内
        ↓
⑦ 导出 .docx（含 Word 原生表格）
   · 任务与文书自动记入「最近文书」，可打开、可溯源、可二次编辑
```

## 五、配套形态（扩宽使用面）

| 形态 | 作用 | 边界 |
|---|---|---|
| **桌面悬浮球**（Electron） | 任意应用内选中文字 → 翻译 / 关联查找法规（走主程序本地法库）/ 询问 AI；可把选中文字推送给小元预填任务材料 | 辅助形态，非主交付路径 |
| **离线单文件演示站** | 零依赖、双击即开；含「引用自检交互实验室」，**可自己注入假条文号看它当场被点名** | 演示用，不替代桌面端 |
| **移动端演示 APK** | 法元的轻量伴随入口（法规 / 翻译 / 模板 / 待办） | **生态演示**，不含桌面端全量法库、Excel 导入、文书智能体与 .docx 交付 |

> **移动端口径**：措辞为「法元的移动端生态演示」，不称「移动版法元」。

## 六、场景可扩展性

法元的产品定位不是「一个法律工具」，而是「**法域 × 文书场景**平台」：

- **法域可扩展**：日本 / 美国已内置；中文全量法库按权威公开源接入属后续路线图（`flk.npc.gov.cn` 等）。
- **文书场景可扩展**：任务流水线是模板化步骤引擎——**新增任务类型 = 新增一条模板**。
- **平台可迁移**：确定性引用自检这套「产出 + 逐条对账」的范式，
  可迁移到任何**有权威数据源、且结论必须可溯源**的高风险域（医疗指南、金融监管条文、工程规范）。

> **口径边界**：「验证期聚焦涉外」≠ 能力上限。当前阶段把涉外做透，是资源聚焦，不是产品边界。

## 七、场景相关的如实说明

1. **中文全量法库未内置**：当前中文能力 = 内置示例条文 + 美国宪法官方中译 + 中文文书模板。
   应用**不生成无依据的译文**。
2. **法规内容边界**：法条原文版权归各官方来源（e-Gov / govinfo / 国家法律法规数据库）。
   应用仅作本地检索与引用，**结论以官方文本为准，不构成法律意见**。
3. **演示包内的法库规模**：本仓库为体积与版权合规，仅内置少量演示条文；
   完整 152,940 条位于桌面端安装包的预置库（约 467 MB），随安装包分发。
