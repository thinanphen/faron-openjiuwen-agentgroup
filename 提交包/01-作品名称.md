# 01 · 作品名称

**法元 · Faron —— 可信的涉外法律文书 Agent 团队**

| 项 | 内容 |
|---|---|
| 作品名称 | **法元 · Faron（文书智能体「小元」）** |
| 一句话定位 | 一个跑在律师/法务本机上的「办案数字员工」：听懂委托 → 自主检索本地真实法条 → 起草并逐条质检 → 交付可溯源、可双击打开的 .docx 文书，全程数据不出本机 |
| 参赛赛事 | 首届 **openJiuwen 智能体创新大赛**（主题「智体共生 · 创新无限」） |
| 应用方向 | **🏢 办公**（文档处理 + 流程自动化 + 知识管理三者的交叉） |
| 承载框架 | openJiuwen `agent-core`（`openjiuwen.agent_teams` 原生 AgentGroup） |
| 作品形态 | Windows 桌面应用（Tauri 2 + React + SQLite）＋ 桌面悬浮球（Electron）＋ 离线单文件演示站 ＋ Android 演示 APK |
| 提交版本 | 赛事版 **0.7.3** |
| 作品名规范 | 纯 ASCII 可用写法：`法元Faron`（已避免汉字状态下的符号） |

---

## 为什么是这个名字

- **法**：法律、法条——产品的能力边界。
- **元**：根本、元数据——它不生成「看起来像法条」的文字，而是**从真实法条库取数并逐条对账**。
- **Faron**：英文传播名，与中文名同源。
- **小元**：文书智能体的人格化称呼。

---

## 与本届主题的对应

大赛简介写道：智能体技术「正加速从『能对话』迈向『能做事』」。

「法元」正是这条线上的作品——它**不是一个会聊天的法律助手**，而是一个**能交付成果的数字员工**：

| 「能对话」阶段 | 「能做事」阶段（法元） |
|---|---|
| 回答法律问题 | **输出可归档的 .docx 文书** |
| 引用「大概是这样」 | **逐条引用本地真实法条 + 官方来源** |
| 无法验证 | **代码级规则逐条对账，未覆盖项当场点名** |
| 数据上传云端 | **全程本地，数据不出本机** |

---

## 本作品与 openJiuwen 的关系（一句话）

> **openJiuwen 的 AgentGroup 解决「一起干活」；法元补上「干得可信」。**

多个 Agent 协同产出的每一处法条引用，都由一段**不经过模型**的确定性规则
逐条判定真伪与适用性——**评委可以不带任何 API Key，在本地亲手复现这个判定**。
