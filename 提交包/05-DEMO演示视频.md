## 三、重剪执行清单

### 步骤

1. **录屏**（1080p / 30fps）：按 `shotlist.csv` 逐镜录制，文件名严格按「素材文件」列
2. **配音**：按 `narration-3min.txt` 录音
3. **剪辑**：导入 `subtitles-3min.srt` 作为旁白轴；片头用 `intro-dark.png`（1.5s 静帧 + 淡入），片尾用 `end-card.png`（2s 静帧），全程右下角叠 `corner-badge.png`
4. **变速**：操作段 1.5–2×；**关于结论的镜头一律原速**（尤其 S5）
5. **导出**：1080p / H.264，目标 **≤ 60 MB**

### 拍摄前必做

- [ ] 首启一次让法库与 FTS 索引就绪；离线试跑「检索 + 演示模式全流程」
- [ ] 演示词用必命中词：日 `契約` / `民法` / `遺留分`，美 `trademark` / `bankruptcy`
- [ ] **S5 埋雷镜头先在本机跑通一遍**，确认「未覆盖自动点名」的原文措辞再开机录
- [ ] 确认演示机是 **0.7.3**（任务栏 / 安装向导 / 关于页三处图标核对）
- [ ] 录屏前清空「最近文书」与任务历史里的真实案卷；API Key 只露 `enc:` 前缀
- [ ] 关闭系统通知与来电弹窗

### 拍摄红线（踩了要扣分）

| 红线 | 说明 |
|---|---|
| **别把「自我进化」页当已实现功能拍** | 它是 0.8.0 规划方案稿的可视化页，入片必须打「方案稿」角标；**不能说「联邦学习 / 强化学习 / 聚合大模型权重」**，要说「编排配方进化」 |
| **中文法库口径** | 只说「当前中文以内置示例 + 中文文书模板演示，全量在路上」，不说已覆盖中文全量 |
| **移动端措辞** | 「法元的移动端生态演示」，不说「移动版法元」 |
| **模型模式** | 若走演示模式（未配置模型接口），**旁白必须先念**「当前未配置模型接口，计划为预设流水线，但工具调用真实执行」 |
| **未配置模型接口时** | 只录**法规查询 + 自检反例**这两段确定可跑的部分，不要假装跑通了文书生成 |
