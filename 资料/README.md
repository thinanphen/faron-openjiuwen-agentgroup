## 三个值得重点看的地方

### ① 产品演示站 `04-产品演示站/demo.html`

单文件、零依赖、**双击就能离线打开**。里面的「**引用自检交互实验室**」
允许你**自己注入一个库里不存在的条文号**，看它当场被点名——
这是整个作品最硬的差异点，且**不需要装软件、不需要配模型 Key**。

线上地址：https://faron-demo.pages.dev

### ② 演示视频的分镜与字幕包 `01-演示视频-分镜与素材/`

**3 分钟版的分镜、字幕、配音稿、品牌素材全部就绪**：

| 文件 | 用途 |
|---|---|
| `13-演示视频分镜脚本.md` | 主大纲：评分点映射、三个「杀手镜头」、拍摄红线、上场检查单 |
| `分镜与字幕包/shotlist.csv` / `.json` | 镜头表（剪映/剪辑台对齐用） |
| `分镜与字幕包/subtitles-3min.srt` | 主版 3:00 字幕（27 条，末条收在 180.0 s） |
| `分镜与字幕包/subtitles-90s.srt` | 送审版 1:30 字幕 |
| `分镜与字幕包/subtitles-30s-vertical.srt` | 竖版 0:30 切片字幕 |
| `分镜与字幕包/narration-3min.txt` | 配音逐字稿（约 560 字，4.5 字/秒） |
| `品牌素材/*.png` | 片头帧（深/浅底）、落版、竖版片头、角标 ×2 |

> ⚠️ **成片当前是 7 分 13 秒，超出赛规「3 分钟以内」的 2.4 倍**，
> 需要按上面这套 3 分钟分镜重剪。详见 `../docs/01-贴合度评估与整改建议.md` 的 G2。

## 关于本目录的整理改动

为满足 GitHub 与跨平台要求，做了以下**无损**改动：

| 改动 | 原因 |
|---|---|
| `04-产品演示站：httpsfaron-demo.pages.dev/` → `04-产品演示站/` | 原目录名含**全角冒号**，在 Windows 解压时会写入失败 |
| `法元·Faron产品介绍.pptx` → `法元Faron产品介绍.pptx` | `·` 属赛事明令避免的「汉字状态下的符号」 |

| 原 `05-安装包与移动端/` → `05-移动端与安装说明/` | 安装包已剔除，目录名相应收敛 |

材料内容**未做任何删改**。
